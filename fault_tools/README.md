# Fault Mask Format

## Purpose
Describe the JSON mask used to drive fault injection (generated by `gpu_fault_gen.py` and loaded by `apu_se.py`).

## File(s)
- Generator: `gpu_fault_gen.py`
- Example: `mask.json`
- Loader: `apu_se.py`

---

# Top-level structure
A mask file is a JSON array. Each element corresponds to one simulation run (mask id).

### Mask object fields
- `id`: int (0..num_sims-1)
- `fault_model`: `"transient"` | `"hard"`
- `component`: `"vgpr_file"` | `"sgpr_file"` (from `gpu_config_regfiles.json`)
- `rf`: `"vrf"` | `"srf"`
- `num_faults`: int
- `faults`: list of fault objects

### Transient-only fields
- `time_unit`: `"tick"`
- `gaussian`:
  - `mu`: center of the Gaussian distribution
  - `sigma`: standard deviation
  - `max_ticks`: maximum simulation tick
  - `tick_start`: beginning of the injection window
  - `tick_end`: end of the injection window

The `tick_start` and `tick_end` parameters restrict transient fault injection to a specific simulation window (typically the kernel execution window).

---

# Fault object: transient

### Required fields
- `tick`: int
- `location`: object

### location fields (VRF)

- `type`: `"regfile"`
- `rf`: `"vrf"`
- `instance`: `{ cu: int, simd: int }`
- `phys_reg_index`: int
- `lane`: int
- `lane_bit`: int
- `bit_index`: int (`lane * bits_per_lane + lane_bit`)

### location fields (SRF)

- `type`: `"regfile"`
- `rf`: `"srf"`
- `instance`: `{ cu: int, simd: int }`
- `phys_reg_index`: int
- `bit_index`: int

---

# Fault object: hard (stuck-at)

Same structure as transient faults **without `tick`**, plus:

- `mode`: `"stuck_at"`
- `stuck_value`: `0 | 1`

---

# Constraints / ranges (current configuration)

### VRF
- `cu`: 0..3
- `simd`: 0..3
- `phys_reg_index`: 0..2023 (or 0..2047 depending on `vreg-file-size`)
- `lane`: 0..63
- `lane_bit`: 0..31
- `bit_index`: 0..2047

### SRF
- `cu`: 0..3
- `simd`: 0..3
- `phys_reg_index`: 0..2047
- `bit_index`: 0..31

# Known limitations / TODO

- Some masks may omit `location.rf`; loader defaults to `"vrf"`. Standardize by always emitting `location.rf`.
- Tick must be within simulated runtime; otherwise injection will never trigger.
- Transient faults should ideally be injected within the kernel execution window using `--tick-start` and `--tick-end`.

# Example commands

## Transient faults

```bash
python3 gpu_fault_gen.py \
  --config gpu_config_regfiles.json \
  --component vgpr_file \
  --fault-model transient \
  --num-sims 10 \
  --faults-per-sim 5 \
  --max-ticks 600000 \
  --tick-start 100000 \
  --tick-end 500000 \
  --sigma-frac 6 \
  --seed 1 \
  --output masks_transient.json
